# copyreader

LLM text editing with a human-in-the-loop.

## Installing

To install this package, run

```console
pip install .
```

## Usage

To run the app, install this package with app dependencies with

```console
pip install .[app]
```

To launch the Streamlit server, run


```console
streamlit run copyreader/app/app.py
```

## Contributing

To contribute, install an editable version of this package, along with developer dependencies and pre-commit hooks, with:

```console
pip install -e .[dev]
pre-commit install
```
